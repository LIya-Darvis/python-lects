Основное требование к программе

1. ‎Прочитать данные из файла data.json.
2. ‎Обработать данные в соответствии с заданием.
3. Записать результат в файл result.json.


Пример задания

Написать программу, которая:
1. ‎Считает количество заказов по каждому статусу.
2. Находит статус с наибольшей общей суммой заказов.
3. ‎Находит клиента с наибольшей суммой заказов.
4. ‎Считает общую сумму всех доставленных заказов.
5. ‎Записывает результат в файл result.json.
